Project Overview

GoodGather is a community-driven social development platform designed to bring people together to address social and environmental challenges. The platform provides an organized space where individuals can create, discover, and participate in various community service initiatives.

It focuses on promoting social responsibility through activities such as winter clothing distribution, food donation campaigns, environmental cleanups, tree plantation programs, health camps, and educational initiatives. By connecting volunteers and community members, GoodGather makes it easier to coordinate social activities and contribute to meaningful causes.

The platform aims to encourage community participation, strengthen social connections, and create opportunities for individuals to make a positive impact on society.

Technologies Used

Frontend

- Next.js: React-based framework for building the application and managing routes.
- React.js: Building reusable and interactive user interface components.
- TypeScript: Providing static type checking and improving code reliability.
- Tailwind CSS: Creating responsive and maintainable UI designs.
- DaisyUI: Providing pre-built UI components.
- HeroUI: Enhancing the user interface with reusable components.
- Lucide React: Providing modern and consistent icons.
- React Toastify: Displaying interactive notifications and feedback.

Backend

- Node.js: JavaScript runtime for server-side development.
- Express.js: Building RESTful APIs and handling server-side requests.
- MongoDB: Storing and managing application data.

Authentication

- Better Auth: Handling user authentication and session management.
- MongoDB Adapter: Connecting Better Auth with MongoDB for authentication data storage.

Deployment

- Vercel: Deploying the frontend application.
- Render: Hosting the backend server.

Benefits of the Platform

- Community Engagement: Encourages people to participate in meaningful social activities.
- Social Support: Helps organize donation campaigns and humanitarian initiatives for underprivileged communities.
- Environmental Awareness: Promotes environmental protection through cleanup and tree plantation activities.
- Event Management: Makes creating, updating, and managing community service events easier.
- Volunteer Participation: Provides opportunities for individuals to discover and join social initiatives.
- Better Coordination: Brings community members together through an organized event management system.
- Accessibility: Provides a responsive platform that users can access across desktop, tablet, and mobile devices.
- Social Responsibility: Inspires individuals to contribute to society and create positive change.
